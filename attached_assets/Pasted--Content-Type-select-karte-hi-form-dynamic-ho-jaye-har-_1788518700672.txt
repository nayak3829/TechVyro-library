"Content Type" select karte hi form dynamic ho jaye — har type ke andar ye fields aayenge:

Exams → Exam group (SSC/Defense/Banking/Railways/UPSC/Teaching) → specific exam (CGL/CHSL/NDA/CDS...)
School → Class (1–12) → Board (CBSE/ICSE/State) → Subject
College → Course (B.Tech/B.Sc/B.Com/BA) → Branch/Stream → Semester → Subject
Diploma → Branch (Mechanical/Civil/CS etc.) → Semester → Subject

Database side — ek hi generic structure kaafi hai, alag-alag table banane ki zarurat nahi:

content_type   → "exam" | "school" | "college" | "diploma"
category       → e.g. "SSC", "Class 10", "B.Tech", "Polytechnic - Mechanical"
subcategory    → e.g. "CGL", "CBSE", "3rd Semester", "4th Semester"
subject/tags   → optional, free text ya multi-select

Ye flexible hai — kal agar koi 5th type add karna ho (jaise "Entrance Exams" for JEE/NEET separately), bina schema todhe ho jayega.
